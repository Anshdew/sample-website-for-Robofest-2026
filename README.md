# ROBOFEST 2026 — Landing Page

An original, responsive landing-page concept for the ROBOTiX Club recruitment challenge at NIT Raipur.

## Theme: Workshop of the Future
A dark engineering-workbench aesthetic with cyan circuit energy, warm orange highlights, a custom CSS robot, technical labels, and bold editorial typography. The page should feel like a robotics lab: experimental, precise, and a little playful.

## Sections
- Hero section with headline and calls to action
- About ROBOFEST section
- Three concept challenge cards: Line Runner, Robo Soccer, and BotLab
- Experience / event-value section
- Registration call to action
- ROBOTiX Club footer

## Tech used
- HTML5 for semantic page structure
- CSS3 for responsive layouts, robot illustration, event graphics, hover effects, and animations
- Vanilla JavaScript for mobile navigation and scroll reveal
- Google Fonts: Space Grotesk and DM Mono (internet connection required for the fonts; fallbacks are included)

## Run locally
1. Download and unzip the project.
2. Open `index.html` in a browser.
3. For a smoother workflow, open the folder in VS Code and use the Live Server extension.

No build step or package installation is required.

## Before submitting
1. Replace the demo Instagram link in the registration CTA with an official ROBOTiX/ROBOFEST registration or information link.
2. Confirm official event names, dates, and rules with the club. The three challenge names in this concept are illustrative and are labelled as such on the page.
3. Test at mobile and desktop widths.
4. Create a GitHub repository and upload `index.html`, `style.css`, `script.js`, and this README.
5. Enable GitHub Pages in the repository settings for a live URL.
